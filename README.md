**Vice Cover Studio** — turn your photos and a caption into a GTA-style multi-panel poster, and export it as a PNG. Five layouts (hero + 3, grid 4, grid 9, full bleed, tilted snap), four colour grades (Sunset, Neon Night, Vice City, Heat Wave), bold Anton lettering with a neon Pacifico subtitle, a heat-star meter and a badge ribbon — in 1080×1080, 1080×1350 and 1920×1080. Everything runs offline in the browser: photos are read on your own machine and never uploaded.

## Run it

```sh
node serve.mjs
```

Then open http://localhost:8123 — pick photos, click a panel and a photo to fill it, drag a photo to move it, and hit **Export PNG**. `?shot=editor` and `?shot=cover` set up fixed scenes for screenshots.
